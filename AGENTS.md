# Agents

Read `CLAUDE.md`: it is the instruction file for every agent working in this folder (Claude Code, Codex, Cursor). The studio's per-turn instructions are in `studio/system-prompt.md`.

Codex: the studio runs Claude Code headlessly (`claude -p`). To use Codex instead, open this folder in Codex and work from `CLAUDE.md` directly; the preview (`./instagram-preview/serve.sh`) and every script work the same.
