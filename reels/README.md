# reels

One numbered folder per finished series, in posting order (`01-slug`, `02-slug`, ...). The mp4s are local only (git-ignored); `cover.jpg` and this list are committed. Where there are several music variants, the **main** one is listed first; it is the one copied to `instagram-preview/assets/mine/reel-N.mp4`.

Regenerate a series from its run folder: `full-pipeline/runs/<run>/` has the job ids, the picks and the stitch settings.
